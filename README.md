# nodejs-hw

Node.js homework assignments — Express + MongoDB (GoIT fullstack course).

## Setup

```bash
npm install
cp .env.example .env  # fill in PORT and MONGO_URL
npm run dev
```

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start server with nodemon (hot reload) |
| `npm start` | Start server with node |
| `npm run lint` | Run ESLint |
